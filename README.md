# Шагомер (виджет)

Многоязычное консольное приложение для отслеживания количества шагов с визуализацией прогресса.  
Позволяет добавлять шаги, устанавливать дневную цель, просматривать статистику и историю.

## Особенности
- Добавление шагов за текущий день (суммирование).
- Установка дневной цели (по умолчанию 10000 шагов).
- Отображение прогресса в виде цветного прогресс-бара.
- История за последние 7 дней.
- Экспорт данных в CSV.
- Хранение данных в локальном JSON-файле.
- Цветной вывод в терминале (где поддерживается).
- Поддержка аргументов командной строки для автоматизации.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости (указаны ниже).

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama` (опционально).  
   Запуск: `python step_counter.py --add 5000`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node step_counter.js --add 5000`

3. **Go**  
   Запуск: `go run step_counter.go --add 5000`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run -- --add 5000`

5. **Java**  
   Сборка: `javac -cp gson.jar StepCounter.java`  
   Запуск: `java -cp .;gson.jar StepCounter --add 5000`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --add 5000`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o step_counter step_counter.cpp -ljsoncpp`  
   Запуск: `./step_counter --add 5000`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc -cp gson.jar StepCounter.kt`  
   Запуск: `kotlin -cp .;gson.jar StepCounterKt --add 5000`

## Использование

Общие аргументы командной строки (везде, где поддерживается):

- `--add <число>` – добавить шаги за сегодня (суммируется с уже имеющимися).
- `--show` – показать сегодняшние шаги, прогресс к цели и историю за неделю.
- `--goal <число>` – установить дневную цель.
- `--history` – показать историю за последние 7 дней.
- `--reset` – сбросить все данные.
- `--export-csv <файл>` – экспортировать историю в CSV.
- `--help` – справка.
